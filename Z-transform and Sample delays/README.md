# Z-transform and Sample Delays

This folder contains the MATLAB implementation and answers for the **Z-transform and Sample Delays** assignment. It covers how a finite signal maps to its Z-transform, how a one-sample delay appears as multiplication by $z^{-1}$, and how a simple two-tap FIR system is described by its transfer function $H(z)$.

---

## Files

- [`Z_transform_sample_delays.m`](Z_transform_sample_delays.m): MATLAB script for Part 1, Part 2 and the modified system from Task 6. It saves all plots to `figures/`.
- `figures/`: PNG plots generated by the script:
  - `part1_original_and_delayed.png`
  - `part2_input_output.png`
  - `task6_input_output.png`

## How to Run the Script

Open MATLAB in this directory, or run this command in a terminal:

```bash
matlab -batch "run('Z_transform_sample_delays.m')"
```

No Symbolic Math Toolbox is required.

## Part 1: A Signal and Its Z-transform

### Specifications
The signal starts at $n = 0$ and is zero outside the listed samples:

$$x[0] = 1, \quad x[1] = 2, \quad x[2] = 1$$

$$X(z) = \sum_{n} x[n]\,z^{-n} = 1 + 2z^{-1} + z^{-2}$$

### Plot: Original and Delayed Signal
![Original signal x[n] and one-sample delay x[n-1]](figures/part1_original_and_delayed.png)

### Questions & Answers

#### 1. Identify the sample represented by each term in X(z).
> **Answer:** Each term $x[k]\,z^{-k}$ is the sample at index $k$. The power of $z^{-1}$ gives the sample's position, and the coefficient gives its value.
>
> | Term in $X(z)$ | Power of $z^{-1}$ | Sample |
> | :---: | :---: | :---: |
> | $1$ | $z^{0}$ | $x[0] = 1$ |
> | $2z^{-1}$ | $z^{-1}$ | $x[1] = 2$ |
> | $z^{-2}$ | $z^{-2}$ | $x[2] = 1$ |

#### 2. Write the Z-transform of the delayed signal.
> **Answer:** The delayed signal is $x_d[n] = x[n-1]$, so $x_d[0] = 0$, $x_d[1] = 1$, $x_d[2] = 2$ and $x_d[3] = 1$:
>
> $$X_d(z) = 0 + 1z^{-1} + 2z^{-2} + 1z^{-3} = z^{-1} + 2z^{-2} + z^{-3} = z^{-1}X(z)$$

#### 3. Explain why delaying the signal by one sample multiplies X(z) by z⁻¹.
> **Answer:** In $X(z)$, the exponent of $z^{-1}$ in each term is the index of that sample. A one-sample delay moves every sample from index $n$ to index $n+1$, so every exponent goes up by one. Multiplying by $z^{-1}$ does exactly that.
>
> **Derivation:** Substitute $m = n - 1$:
>
> $$\mathcal{Z}\{x[n-1]\} = \sum_{n} x[n-1]\,z^{-n} = \sum_{m} x[m]\,z^{-(m+1)} = z^{-1}\sum_{m} x[m]\,z^{-m} = z^{-1}X(z)$$
>
> This is why $z^{-1}$ is called the **unit delay operator**. In block diagrams, a $z^{-1}$ block is a one-sample memory element.

## Part 2: A System with One Sample Delay

### Specifications
The system averages the current input and the previous input. The input is zero before $n = 0$.

$$y[n] = 0.5x[n] + 0.5x[n-1]$$

$$Y(z) = 0.5X(z) + 0.5z^{-1}X(z) \quad\Longrightarrow\quad H(z) = \frac{Y(z)}{X(z)} = 0.5 + 0.5z^{-1}$$

The input is padded with one zero, `xInput = [x 0]`, so that the final output sample $y[3]$ is visible.

### Plot: Input and Output, $H(z) = 0.5 + 0.5z^{-1}$
![Input x[n] and output y[n] for H(z) = 0.5 + 0.5z^-1](figures/part2_input_output.png)

### Questions & Answers

#### 4. Calculate y[0], y[1], y[2] and y[3] by hand. Compare them with MATLAB.
> **Answer:** With $x[-1] = 0$ and $x[3] = 0$:
>
> | $n$ | $0.5x[n] + 0.5x[n-1]$ | $y[n]$ |
> | :---: | :---: | :---: |
> | $0$ | $0.5(1) + 0.5(0)$ | $0.5$ |
> | $1$ | $0.5(2) + 0.5(1)$ | $1.5$ |
> | $2$ | $0.5(1) + 0.5(2)$ | $1.5$ |
> | $3$ | $0.5(0) + 0.5(1)$ | $0.5$ |
>
> **Comparison:** MATLAB's `filter(b, a, xInput)` returns `[0.5 1.5 1.5 0.5]`, which matches the hand calculation exactly. The script prints both vectors and their maximum absolute difference, which is $0$.
>
> The same result follows from multiplying the polynomials:
>
> $$Y(z) = H(z)X(z) = (0.5 + 0.5z^{-1})(1 + 2z^{-1} + z^{-2}) = 0.5 + 1.5z^{-1} + 1.5z^{-2} + 0.5z^{-3}$$

#### 5. Explain how b = [0.5 0.5] represents the two terms in H(z).
> **Answer:** `filter(b, a, x)` uses the numerator coefficients `b` in ascending powers of $z^{-1}$:
>
> $$H(z) = \frac{b(1) + b(2)z^{-1} + \dots}{a(1) + a(2)z^{-1} + \dots}$$
>
> - `b(1) = 0.5` is the coefficient of $z^{0}$. It multiplies the **current** input $x[n]$.
> - `b(2) = 0.5` is the coefficient of $z^{-1}$. It multiplies the **previous** input $x[n-1]$.
> - `a = 1` means there is no feedback, so the denominator is $1$ and the system is FIR.

## Task 6: Modified System $H(z) = 0.8 + 0.2z^{-1}$

The coefficients are changed to `b = [0.8 0.2]`, so $y[n] = 0.8x[n] + 0.2x[n-1]$. The script runs this case after Part 2 and saves a separate figure.

### Plot: Input and Output, $H(z) = 0.8 + 0.2z^{-1}$
![Input x[n] and output y[n] for H(z) = 0.8 + 0.2z^-1](figures/task6_input_output.png)

### Questions & Answers

#### 6. Change the system to H(z) = 0.8 + 0.2z⁻¹. Which input sample now has more influence on the output?
> **Answer:** The **current input sample $x[n]$** now has more influence. Its weight is $0.8$, four times the $0.2$ weight on the previous sample $x[n-1]$.
>
> | $n$ | $0.8x[n] + 0.2x[n-1]$ | $y[n]$ |
> | :---: | :---: | :---: |
> | $0$ | $0.8(1) + 0.2(0)$ | $0.8$ |
> | $1$ | $0.8(2) + 0.2(1)$ | $1.8$ |
> | $2$ | $0.8(1) + 0.2(2)$ | $1.2$ |
> | $3$ | $0.8(0) + 0.2(1)$ | $0.2$ |
>
> **Explanation:** With equal weights ($0.5/0.5$), the output is a symmetric average: $y[1] = y[2] = 1.5$ and the output is smeared evenly over two samples. With $0.8/0.2$, the output closely follows the shape of the input $\{1, 2, 1\}$. The peak stays at $n = 1$ ($y[1] = 1.8$) and the "tail" from the delayed term is small ($y[3] = 0.2$). The system now smooths less and responds faster. The coefficients still sum to $1$, so the DC gain is unchanged: $H(1) = 0.8 + 0.2 = 1$.
